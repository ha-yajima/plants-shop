# 植物ショップ　サイト (HTML/CSS)

## 概要
架空の植物店のコンセプトやメニューを紹介する、レスポンシブ対応のWebサイトです。

## 使用技術
- HTML5 (セマンティックなタグ選定)
- CSS3 (Flexbox, Gridレイアウト)

## 注力したポイント
- **レスポンシブデザイン:** 画面サイズに関わらずレイアウトが崩れないよう、メディアクエリを活用してスマートフォン・PC両方への最適化を行いました。
- **SEOとアクセシビリティ:** 検索エンジンやスクリーンリーダーに配慮し、正しい文書構造（見出しタグの順序など）を意識してコーディングしました。
- **ビジュアルデザイン:** 植物ショップのブランドイメージを損なわないよう、余白の使い方や配色にこだわり、清潔感のあるデザインを再現しました。
