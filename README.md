# 植物ショップサイト（HTML/CSS）

## 概要
架空の植物店のコンセプト・商品・アクセスを紹介する、レスポンシブ対応のWebサイトです。<br>
ロゴから配色・レイアウトまで、デザイン全体を自分で手がけました。<br>
個人制作です。<br>

## 使用技術
- HTML5（セマンティックなタグ選定）
- CSS3（Flexbox・Gridレイアウト・メディアクエリ）

## 注力したポイント
- **オリジナルデザイン：** ロゴを自作し、余白・配色・フォント選びにこだわることで、植物店らしい清潔感のあるビジュアルに仕上げました。
- **商品詳細のポップアップ：** productページでは商品ごとに詳細をポップアップ表示できる仕組みを実装し、回遊性の高いUIを目指しました。
- **レスポンシブデザイン：** スマートフォン・PC両方で崩れないレイアウトをメディアクエリで実現しました。

## 苦労した点
ハンバーガーメニューのスマホ表示が繰り返し崩れる問題に直面し、表示条件やCSSの優先順位を一つずつ確認しながら修正を重ねました。<br>
粘り強くデバッグすることで最終的に安定した動作を実現しました。
